# MIDI Roundabout

A PCB that lets you route TRS-A, DIN-5 or TRS-B MIDI signals. It uses the MIDI Thru circuit with 220 ohm resistors on the two signal lines.

The switch is a [DP3T switch](https://www.digikey.com/en/products/detail/c-k/JS203011SCQN/7056055) that is available for PCBA on JLCPCB. The BOM and part placement files are available in the Gerber files folder.
